# Predicting Customer Churn: A Data-Driven Analysis of Subscription Customer Behaviour

Capstone project for the IDRA (India Data Research Academy) Data Science & AI Training Program. Builds a classification model to predict telecom customer churn from account, service and billing attributes, and translates the findings into evidence-based retention recommendations.

## Overview

| | |
|---|---|
| **Task** | Binary classification — predict `Churn` (Yes/No) |
| **Dataset** | IBM Telco Customer Churn (7,043 customers, 21 attributes) |
| **Best model** | Random Forest — 76.5% accuracy, 77.5% recall, F1 = 0.637, ROC-AUC = 0.846 |
| **Key drivers** | Contract type, tenure, monthly/total charges, internet service, payment method |

## Key Findings

1. **Contract type** is the strongest churn driver — month-to-month customers churn at **42.7%** vs. **2.8%** for two-year contracts.
2. **Tenure** matters most in the early relationship — churned customers have a median tenure of **10 months** vs. **38 months** for retained customers.
3. **Fiber-optic internet** customers churn at **41.9%**, more than double DSL customers (19.0%).
4. **Electronic check** payers churn at **45.3%**, over 2x every other payment method.
5. The trained Random Forest model correctly flags **~3 in 4 actual churners** (77.5% recall) on held-out data.

## Methodology

1. **Cleaning** — fixed a `TotalCharges` data-type issue, resolved 11 structurally-missing values (new customers with `tenure = 0`), collapsed redundant category labels, checked for duplicates and outliers (none found).
2. **Preprocessing** — label/one-hot encoding, `StandardScaler` fit only on the training split (no leakage), 80/20 stratified train-test split.
3. **EDA & statistics** — distribution, group and correlation analysis to surface churn drivers.
4. **Modelling** — Logistic Regression (interpretable baseline) and Random Forest (`class_weight="balanced"` for both, to handle the 73/27 class imbalance).
5. **Evaluation** — accuracy, precision, recall, F1, ROC-AUC, confusion matrices, train/test gap check for overfitting.
